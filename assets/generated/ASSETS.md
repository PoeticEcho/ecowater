# EcoWater 이미지 에셋

OG와 생물·풍경은 이 프로젝트에서 이미지 생성으로 제작한 교육 삽화입니다. 논문 사진이나 현미경 실사가 아니며 실제 크기·색·형태의 종 동정 기준으로 사용하지 않습니다. 이전 파비콘 시안은 제외하고 최종 파비콘만 포함합니다.

- dinoflagellate: 와편모조류 유형 확대 삽화
- duckweed: 렘나형 개구리밥 예시
- microcystis: 남조류 군체 예시
- coastal-red-tide / duckweed-pond / river-bloom: 시나리오 풍경
- og.jpg: 1200×630 공유 카드
- favicon.ico, icon-32/180/192/512.png: 브라우저·홈 화면 아이콘

프롬프트 방향: 자연스러운 청록 물빛·올리브 식생·부드러운 햇빛, 연안 가두리/정체 연못/보 상류의 환경을 표현. 확대 이미지는 일반화한 생물 구조, 텍스트·척도 없음. 파비콘은 어두운 물빛 위에 잎·물방울·물결의 단순한 형태.
