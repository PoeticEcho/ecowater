# 에코워터 3D · 배포 전 최종 평가

평가일: 2026-10-25. 대상: 공개 앱의 관찰 → 원인 도감 → 직접 대처 → 회복 → 퀴즈 → 스탬프 흐름.

## 판정

교육용 공개판의 학습 흐름과 에셋 통합을 완료했습니다. 실제 환경을 예측하는 전문 모형으로 평가한 결과가 아닙니다. 실제 iPad Safari의 GPU 출력·프레임률·멀티터치는 별도 기기 검증이 남아 있습니다.

## 화면과 동작 평가

1. **관찰 시작 — 양호.** 세 수역의 풍경 이미지로 선택하고, 미획득 스탬프 3개를 확인할 수 있습니다. 환경설정과 대처방안은 따로 열고 7초 후 접힙니다. 메뉴를 사용하지 않아도 10일차 사건이 발생합니다.
2. **원인 도감 — 양호, 읽기 분량 주의.** 햇빛·양분·흐름 아이콘을 같은 선형 스타일로 통일했습니다. 생성 삽화 표기와 자연 속 역할 설명이 있어 ‘모든 플랑크톤이 해롭다’는 오해를 줄입니다. 긴 도감은 내부 스크롤이 필요하므로 교사는 학습자 읽기 속도에 맞춰 진행해야 합니다.
3. **도구 선택·직접 대처 — 양호.** 도구 이름과 아이콘이 커서 위에 나타나고, 수면 밖에서는 점선과 안내를 표시합니다. 배치 후 표시가 사라집니다. 추천 위치 배치는 정밀한 포인터 조작이 어려운 사용자에게 대안입니다. 손가락 가림을 피하는 위치 계산은 구현했으나 실제 iPad 터치는 미검증입니다.
4. **회복·기억 확인·스탬프 — 양호.** 실제 조치 후 회복 수치가 충족되어야 퀴즈로 진행합니다. 오답 이유를 읽고 수정할 수 있으며, 두 문제를 이해하면 수역별 스탬프를 받습니다. 점수보다 원인 설명을 강조합니다. 완료한 미션과 스탬프는 이 브라우저에 저장됩니다. 미완료 수역은 재방문 시 처음부터 시작하며, 다른 기기와 동기화하지 않습니다.

화면 증거는 이 평가 작업에서 공개 앱을 직접 조작하며 캡처했습니다. 브라우저에서 WebGL이 비활성화되어 화면 평가는 2D 호환 모드에 한정합니다. 3D 배경의 최종 GPU 렌더링 품질을 화면 평가로 확인했다고 주장하지 않습니다.

## 구현과 자동 검사

- 세 시나리오: 정상 → 이상증식 → 피해 → 사용자 조치 → 회복.
- 무조작 상태의 10일차 사건과 관찰 대기, 조기 예방, 읽는 동안 시간 정지.
- 세 스탬프 조건: 회복/예방 + 원인 도감 완료 + 두 문항 정답. 미해결 미션·오답·자유 실험에서 부정 획득 차단.
- 어류 개체별 움직임, 경계·가두리 범위, 저산소 행동, 폐사의 비가역성.
- 새 수변 지오메트리의 유한 좌표·인스턴스 변환 확인, 빌드 성공.

## 접근성과 기기 검증 한계

- 주요 버튼 이름, 도구 이름, 스탬프 미획득/획득 텍스트가 제공됩니다. 완료는 색만으로 전달하지 않습니다.
- 스탬프 확대 애니메이션은 reduced-motion 설정을 존중합니다. 페이지 확대 제한을 제거했습니다.
- 대비율 전체 측정, VoiceOver 실제 낭독 순서, 확대 시 화면 재배치, 실제 iPad에서의 회전·핀치·배치·수거 드래그는 별도 확인이 필요합니다. WCAG 준수 인증이나 60fps 보장을 의미하지 않습니다.
- 수온·영양염류·독성·방제 효과는 연구 예측치가 아닙니다. 생성 그림은 현미경·현장 사진이나 종 동정 자료가 아닙니다.

## 수업 권장 진행

소개 30초 → 세 수역 각 2~3분 → 스탬프 3개와 비교 리포트 1분. ‘어떤 조건이 겹쳤는가’, ‘어떤 조치가 원인을 줄였는가’, ‘모든 개체를 없애는 것이 목표인가’를 말로 설명하게 합니다. 10분은 권장 수업 구성이고 학습 완료 시간을 강제하지 않습니다.

## 이어가기 보완

완료 기록 저장·복원, 스탬프 3개 복원, 앱 기록만 초기화, 손상·알 수 없는 버전·저장 차단·용량 초과 처리를 자동 검사했습니다. 새 탐험은 확인 화면을 거치며, 기록 유지 선택 시 저장된 스탬프를 보존합니다. 버튼의 최소 터치 영역을 44px로 보완하고 도감·완료 화면의 버튼 묶음이 좁은 폭에서 줄바꿈하도록 했습니다. 실제 iPad 검증 한계는 위와 같습니다.
